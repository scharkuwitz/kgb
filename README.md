# KGB

A small, general-purpose knowledge base. Give it your documents, then ask questions in everyday language.

## What it does

- **Reads what you have.** Scans, photos, PDFs, spreadsheets and text documents all go in the same way.
- **Organizes it.** The useful facts are pulled out and kept as clear, individual entries, each linked back to where it came from.
- **Answers plainly.** Ask for something in your own words and get the matching entries, with their source, instead of a pile of files to dig through.
- **Stays tidy.** Adding the same document twice changes nothing, and the whole index can be rebuilt at any time.

## Status

Early development. It is built in small steps, each one usable and checkable on its own.
